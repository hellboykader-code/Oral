🧲 Collecteur d'e-mails DentWebPro

Récolte automatiquement nom + téléphone + e-mail des cabinets depuis les pages d'annuaires (PagesJaunes…) que VOUS visitez — votre navigateur passe partout, lui.

1 Installer le bouton (une seule fois)

Glissez ce bouton dans votre barre de favoris (Cmd+Shift+B si elle est cachée) :

🧲 Récolter les e-mails

Impossible de glisser ? Créez un favori manuellement et collez le code du bouton (clic droit sur le bouton → copier le lien) dans le champ « URL ».

2 Récolter

  1. Ouvrez pagesjaunes.fr → cherchez dentiste à Paris 75001 (puis 75002, 75003…)
  2. Sur chaque page de résultats, cliquez votre bouton 🧲 Récolter → il détecte les boutons « E-mail » des fiches et enregistre nom + téléphone + e-mail
  3. Page suivante → re-cliquez. La récolte s'accumule (les doublons sont ignorés automatiquement)
  4. Marche aussi sur n'importe quel site affichant des e-mails (annuaires, sites de mairies, associations dentaires…)
⚠️ Toutes les fiches n'ont pas d'e-mail — c'est normal. Sur PagesJaunes, comptez 2 à 5 e-mails par page de 20 résultats. En 15 minutes vous aurez 30-50 e-mails réels.

3 Récupérer le fichier

À chaque clic, le CSV complet (tout ce qui a été récolté) est copié dans votre presse-papiers. À la fin : collez-le (Cmd+V) dans un message à votre assistant → il prépare les brouillons Gmail personnalisés.

💡 Maj+clic sur le bouton = vider la récolte et repartir de zéro.

⚖️ Rappels

Prospection B2B de professionnels référencés publiquement : autorisée avec la mention STOP (opt-out) dans chaque e-mail. Max 20-30 envois/jour. Retirez immédiatement quiconque répond « STOP ».
